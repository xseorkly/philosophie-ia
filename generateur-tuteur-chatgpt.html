Créer mon tuteur de philosophie avec l’IA

Définissez les règles pédagogiques de votre assistant conversationnel. Ce formulaire transforme vos choix en un prompt prêt à copier dans ChatGPT, Claude ou Gemini, sans aucune programmation.

Retour à la formation
1. Définir

Indiquez ce que l’élève doit apprendre et comment l’IA doit l’accompagner.

2. Copier

Le prompt se construit automatiquement à partir du formulaire. Copiez-le.

3. Tester

Collez-le dans ChatGPT, Claude ou Gemini, jouez un élève fictif et vérifiez les réponses.

Qui remplit cette fiche ? Le professeur, en tant que concepteur pédagogique. Qui dialogue ensuite avec l’IA ? Un élève ou, pendant la formation, un participant jouant le rôle de l’élève.

2. Votre prompt prêt à copier

Il est généré automatiquement. Relisez-le : c’est votre consigne pédagogique à l’IA, pas une réponse d’élève. Vous pouvez modifier le texte directement avant de le copier.

3. Utiliser et tester le tuteur

  1. Enseignant concepteur : choisissez le mode ci-dessus et cliquez sur Copier mon prompt.
  2. Conversation classique : ouvrez ChatGPT, Claude ou Gemini, démarrez une nouvelle conversation et envoyez le prompt comme premier message. Attendez que l’IA pose sa première question.
  3. Enseignant testeur : jouez un véritable élève fictif. Envoyez un seul des trois messages ci-dessous dans la conversation, après le prompt de configuration. Vous pouvez ensuite poursuivre le dialogue comme l'élève, en attendant chaque réponse.
  4. Observez : l’IA vous invite-t-elle à définir, justifier et chercher une objection, ou donne-t-elle la solution ? Si une réponse n’est pas satisfaisante, modifiez les règles dans le formulaire, ouvrez une nouvelle conversation et recommencez le même test.
  5. Instructions permanentes : pour ne pas recoller le prompt à chaque fois, choisissez le second mode et collez le texte dans les instructions d’un projet ChatGPT ou Claude, ou dans le champ Instructions d’un Gem Gemini.
Qui écrit ces messages ? C'est le participant qui joue l'élève. Les messages sont formulés à la première personne et intègrent automatiquement le sujet renseigné dans le formulaire. Ils ne remplacent pas le prompt initial : ils sont envoyés ensuite, comme les paroles d'un élève.

Test A · Un élève bloqué

Envoyez ce message dans la conversation déjà configurée, puis attendez la réponse.

Test B · Un élève trop sûr de lui

Essayez ce message dans une nouvelle conversation avec le même prompt initial, pour comparer.

Test C · Un élève qui réclame le corrigé

Recommencez avec le même prompt initial, puis vérifiez si l'IA refuse de faire le devoir à sa place.

Important pour le partage aux élèves : un lien vers une conversation ordinaire ne transmet pas toujours vos règles. Selon l’outil et le compte, un espace configuré (Gem Gemini, projet partagé) peut être transmis ; sinon, distribuez le prompt à coller en début de conversation. Vérifiez les conditions d’âge du service et les règles de l’établissement.
Protection des élèves : n’insérez aucune copie identifiable, information personnelle ou donnée sensible dans cette fiche ou dans un prompt.
